# 🌿 Plant Disease Detection Using Deep Learning

### Developed By  
**Mr. Saqib Kudchikar**

## Project Overview

This project detects plant diseases from leaf images using **Deep Learning**.

The model uses **PlantDoc Dataset** and **MobileNetV2 Transfer Learning** for disease classification.

### Features

- Plant Disease Detection
- Disease Classification
- Health Status Prediction
- Confidence Score
- Fertilizer Recommendation
- Streamlit Web UI

## Technologies Used

- Python
- TensorFlow / Keras
- MobileNetV2
- Streamlit
- NumPy
- OpenCV
- Pillow

## Dataset

**PlantDoc Dataset**

Contains real-world plant images with multiple plants and disease classes.

## Model Used

**MobileNetV2 (Transfer Learning)**

A CNN-based pretrained model used for fast and accurate image classification.

## Run Project

Install libraries:

```bash
pip install -r requirements.txt
```

Train model:

```bash
python train.py
```

Run application:

```bash
streamlit run app.py
```
